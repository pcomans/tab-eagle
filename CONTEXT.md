# Tab Eagle

Tab Eagle is a personal browser workspace for reducing tab and window sprawl so its user can return to focused activity.

## Language

**Tab and window sprawl**:
The accumulation and scattering of open tabs across Chrome windows beyond what the user can comfortably understand and manage.
_Avoid_: Clutter, mess

**Focus**:
The activity the user intends to return to after finding, organizing, or reducing open tabs and windows.
_Avoid_: Productivity

**Management support**:
Help that reduces the cognitive effort required to find, understand, organize, consolidate, or close open tabs and windows.
_Avoid_: Cleanup, tab hygiene

**Work context**:
A coherent activity and the tabs needed to pursue it, even when those tabs are scattered across Chrome windows and macOS Spaces. A work context may span multiple windows and is not necessarily a project or a permanent saved collection.
_Avoid_: Project, workspace, session

**Context recovery**:
Reassembling enough of a remembered work context to resume the intended activity after its tabs or windows have become scattered or the user has switched to something else.
_Avoid_: Tab search, session restore
