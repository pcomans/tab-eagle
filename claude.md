# Claude Instructions

- Always use Material Design 3 components when available; do not hand-roll custom UI controls or patterns that have an MD3 counterpart.
- Tab Eagle card shape must always remain the same across states; reserve stable space for conditional controls or metadata so cards do not jump when status changes.
